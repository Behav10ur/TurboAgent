# TurboAgent

English version: [README.md](README.md)

TurboAgent — терминальный агент на Swift, работающий с **локальной LLM, без облака**. Это мини-агент для мини-задач, которые можно запустить и уйти от макбука: он рассчитан на работу без присмотра, в отличие от облачных агентов (Claude Code, Codex), которым он нужен. Облачных агентов он не заменяет — скорее дополняет для небольших локальных задач.

**Статус: в разработке (pre-MVP).** Stage 1 готов и лежит в этом репо: каркас пакета, точка входа `@main` и интерактивный REPL. Интеграция с моделью и файловые инструменты пока не реализованы. Roadmap намеренно не публикуем — проект на ранней стадии и может измениться или остановиться в любой момент.

## Бэкенд: TurboFieldfare + Gemma

Бэкенд — **TurboFieldfare**, локальный сервер инференса (отдельный проект в `~/Developer/turbo-fieldfare`). Он обслуживает квантованную модель **`gemma-4-26b-a4b-it`** (`gemma4.gturbo`) на `http://127.0.0.1:8080/v1` — OpenAI-совместимый chat-completions API, есть эндпоинты `/health` и `/v1/models`, ключ не требуется. Только Gemma, других моделей не будет.

Сам файл модели (`gemma4.gturbo`, ~14 ГБ) ни в один репозиторий не входит и автоматически не скачивается — его надо скачать заранее вручную и положить как `scratch/gemma4.gturbo` в проект TurboFieldfare. Сервер запускается командой: `.build/release/TurboFieldfareServer --model scratch/gemma4.gturbo --port 8080`.

Клиентская интеграция в этом репо пока не реализована.

## Что работает сейчас

- Сборка и запуск: `swift build` / `swift run turboagent`
- Интерактивный REPL: баннер с рабочей папкой, приглашение и команды:
  - `/help` — список команд
  - `/exit` или `/quit` — выход (Ctrl+D тоже работает)
- Обычный ввод пока просто эхо (`you: ...`) — заглушка до подключения модели
- Цветной вывод в терминале, чистый текст при пайпе

## Принципы дизайна

Сам агент пока не реализован — вот принципы, по которым он будет устроен:

- Текстовый протокол (`@READ путь`, блоки `@EDIT` со search/replace) вместо JSON function calling
- Правки только search/replace — файл целиком никогда не переписывается
- Транскрипт строго append-only — ради prefix reuse на сервере
- Никаких интерактивных y/n во время работы — режим задаётся флагом на старте
- Простой цветной REPL, без TUI и alternate screen

## Требования

- macOS 14+
- Swift 6.x
- Зависимость: [swift-argument-parser](https://github.com/apple/swift-argument-parser) (зафиксирована в `Package.resolved`)

## Быстрый старт

```bash
git clone https://github.com/Behav10ur/TurboAgent.git
cd TurboAgent
swift build
swift run turboagent
```

Или бинарник напрямую: `.build/debug/turboagent`

Примечание: то, что есть в репо сейчас (stage 1, оболочка REPL), работает и без модели. Чтобы общаться с моделью, понадобится также запущенный сервер TurboFieldfare с моделью на месте — см. секцию «Бэкенд» выше.
